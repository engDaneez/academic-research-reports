# Academic Research & Reports Builder

**Agent Skill لبناء ومراجعة التقارير والبحوث الأكاديمية** بالعربية والإنكليزية، مع قواعد للكتابة المنهجية والتوثيق العلمي وتنسيق Word.

> نسخة أولية مستقلة (v1.0.0). مصممة انطلاقاً من منهج عمل متكرر في تقارير الجامعة وبحوث التخرج. ليست نسخة من محادثة شخصية أو من محتوى أي طالب.

## الوظائف

- تجهيز بنية مناسبة لتقرير جامعي أو بحث تخرج أو ورقة بحثية أو تقرير مختبر.
- جمع تعليمات الدكتور أولاً؛ ثم كتابة النص ومراجعته وتنظيم العناوين.
- المحافظة على المحتوى الأصلي عند التحرير، وعدم اختلاق المراجع أو البيانات.
- تطبيق خط أساس عربي: Traditional Arabic، متن 14، عناوين 18/16، تباعد 1.5، A4، هوامش 2.5 سم، مع تحكم بالتنسيق.
- المساعدة في إصدار DOCX والاختبار؛ يجب مراجعة الناتج بصرياً قبل التسليم.

## التثبيت على Codex

بعد نشر هذا المستودع على GitHub، يمكن تثبيت المهارة يدوياً. نزّل المستودع ثم انسخ **المجلد الكامل الذي يحتوي `SKILL.md`** إلى مسار المهارات المعتمد في بيئة Codex الخاصة بك.

```bash
git clone https://github.com/engDaneez/academic-research-reports.git
```

للاستخدام داخل مشروع Codex، ضع المجلد كاملاً في `.agents/skills/academic-research-reports/` داخل مشروعك، بحيث يكون المسار النهائي `.agents/skills/academic-research-reports/SKILL.md`، أو استخدم أداة تثبيت Skills المدعومة في إصدار Codex عندك. قد تحتاج إعادة تشغيل الجلسة لاكتشاف المهارة.

> ملاحظة: نشر ملفات المهارة على GitHub لا يثبّتها تلقائياً داخل ChatGPT.

انسخ المجلد إلى `~/.claude/skills/academic-research-reports/` أو داخل المشروع إلى `.claude/skills/academic-research-reports/`، ثم افتح Claude Code واطلب إعداد تقرير أو بحث جامعي. وجود `SKILL.md` في جذر مجلد المهارة إلزامي.

## تشغيل مولد Word (اختياري)

يتطلب Python 3 وpython-docx:

```bash
python -m pip install -r requirements.txt
python scripts/build_docx.py --input assets/example-report.json --output output/report.docx
python scripts/check_docx.py output/report.docx
python -m unittest discover -s tests -v
```

مثال لبحث تخرج تجريبي:

```bash
python scripts/build_docx.py --input assets/example-graduation-research.json --output output/graduation.docx
```

يمكن فتح `assets/demo-report.docx` لمعاينة تنسيق Word التجريبي بعد الاختبار البصري.

> **مهم:** النماذج تحتوي placeholders وجملاً توضيحية، ليست بحثاً صالحاً للتسليم. بعد إنشاء Word، افتحه وحدّث الفهرس إن كان موجوداً، ثم صدّر/اعرض كل الصفحات بصرياً وصحّح الكسور. المولد لا ينشئ استشهادات APA آلية ولا يفترض أصالة النص، ولا يدعم ترقيم أ/ب/ج/د للتمهيد آلياً.
