# جمع المتطلبات وملف التكليف

## مستلزمات قبل بدء البحث

- اسم البحث أو الموضوع **بالصياغة النهائية**، والاختصاص والمستوى الأكاديمي.
- نوع المخرج: تقرير، بحث أكاديمي، بحث تخرج، تقرير مختبر، مراجعة وتنسيق ملف موجود.
- اللغة: عربي، إنكليزي، أو ثنائي اللغة.
- توجيهات الدكتور والجامعة، نموذج Word، الروبرك، قيود المحتوى، التاريخ النهائي.
- عدد الصفحات أو الكلمات وقيود احتساب الغلاف والملاحق.
- العناوين والفصول المطلوبة، نوع المنهج والبيانات، أي تجارب أو جداول أو صور.
- أسلوب التوثيق: APA/MLA/Chicago/IEEE/هوامش أو أسلوب الكلية.
- المصادر الأساسية التي يجب استخدامها؛ إن لم تتوفر، تصرح المهارة بالحاجة إلى مصادر موثوقة.
- تنسيق الصفحة: الخط، الحجم، الهوامش، التباعد، اتجاه الكتابة، شكل الترقيم.
- المطلوب بالتسليم: DOCX/PDF/نص جاهز، مع حفظ النسخة الأصلية عند التحرير.

**اجمع المعلومات الناقصة فقط.** لا تعطل عملاً ممكناً بسبب غياب اسم الطالب على الغلاف؛ استخدم `[اسم الطالب]` واضحاً إن لزم. لا تنشئ بيانات أكاديمية زائفة.

## فرز نية المستخدم

- "رتب النص" = حافظ على فقراته دون اختصار غير مطلوب.
- "دقق البحث" = راجع الأخطاء وحدّد التعديلات بوضوح.
- "وسع" = توسعة منطقية مدعومة بمصادر أو بيانات لا حشو.
- "جهز تسليم" = إنشاء ملف وQA وتصريح عن الأجزاء غير المكتملة.
- "خط اليد" = إعداد نص صالح للنسخ اليدوي، وليس الادعاء بأنه مكتوب بخط بشري.
