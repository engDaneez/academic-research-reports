# هياكل قابلة للتكييف: ليست إلزامية لكل الجامعات

## 1. تقرير جامعي مختصر (University Report)

1. الغلاف حسب التكليف.
2. مقدمة تمهيدية: السياق، المشكلة، الهدف ونطاق التقرير.
3. النظرة العامة / الخلفية العلمية عند الحاجة.
4. صلب الموضوع: أقسام مرتبة، حجج وأمثلة أو بيانات حقيقية وجداول موثقة.
5. مناقشة / تحليل.
6. الاستنتاجات والخاتمة.
7. التوصيات إذا طُلبت.
8. المصادر، والملاحق عند الحاجة.

تجنّب الإهداء والشكر والآية إذا لم يطلبها الدكتور في تقرير قصير.

## 2. بحث أكاديمي (Research Paper)

- عنوان، ملخص وكلمات مفتاحية عند الحاجة.
- المقدمة: المشكلة والأهمية والأهداف وأسئلة البحث/الفرضيات.
- مراجعة الأدبيات والدراسات السابقة.
- المنهجية: تصميم البحث، العينة، الأدوات، جمع البيانات، التحليل، المحددات والأخلاقيات.
- النتائج **فقط من بيانات حقيقية أو مصادر منشورة**.
- المناقشة: تفسير مقيد بالأدلة والقيود.
- الاستنتاجات والتوصيات.
- المراجع والملاحق.

في الأبحاث النظرية أو الوصفية قد يختلف ترتيب النتائج عن البحوث التجريبية.

## 3. بحث تخرج عربي موسّع (Graduation Research)

تسلسل مرجعي قابل للتعديل:
1. غلاف الجامعة / الكلية / القسم / العنوان / المُعد / المشرف / السنة.
2. آية قرآنية (اختياري وحسب تعليمات الطالب والمؤسسة؛ تأكد من صحة النص والسورة ورقم الآية قبل إضافتها).
3. الإهداء.
4. الشكر والتقدير.
5. الملخص (عربي، وإنكليزي إذا طُلب).
6. فهرس المحتويات، وفهارس الجداول والأشكال إن وجدت.
7. المقدمة: تمهيد، أهمية الموضوع، أسباب الاختيار، مشكلة البحث، الأهداف، الأسئلة/الفرضيات، حدود البحث، المنهج، وخطة البحث.
8. فصول أو مباحث ومطالب وفق خطة معتمدة، مثل 3 مباحث، دون فرض العدد على جميع التخصصات.
9. تحليل / نتائج أو مناقشة بحسب المنهج.
10. الاستنتاجات والتوصيات.
11. الخاتمة.
12. المصادر والمراجع، والملاحق.
13. صفحة ختامية «تم بحمد الله» فقط عندما يطلبها صاحب البحث أو النموذج.

ترقيم الصفحات التمهيدية قد يستخدم أحرف (أ، ب، ج، د) أو أرقاماً رومانية أو بلا ترقيم، وترقيم المتن يبدأ من المقدمة. **تأكد من سياسة الكلية قبل التنفيذ.**

## 4. تقرير مختبر (Lab Report)

- عنوان التجربة والجهة والتاريخ والمشرف عند الحاجة.
- الهدف والنظرية ذات الصلة.
- الأجهزة والمواد وطريقة التنفيذ الآمنة والمعلنة.
- القياسات والبيانات الخام مع الوحدات وعدم اختلاق شيء.
- المعادلات والحسابات والجداول والأشكال.
- تفسير النتائج وحدود القياس ومصادر الخطأ.
- الاستنتاجات والمصادر.

## تقييم البناء

لكل قسم اسأل: لماذا يوجد؟ ما السؤال الذي يجيب عنه؟ ما دليله؟ هل يكرر قسماً آخر؟ هل يرتبط بالنتائج والاستنتاجات؟
