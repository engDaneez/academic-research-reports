# قائمة فحص التسليم

## المدخلات والهيكلة

- [ ] عنوان البحث مطابق للمهمة.
- [ ] متطلبات الأستاذ/الجامعة موثقة ومعمول بها.
- [ ] بنية الأقسام تناسب نوع التقرير أو البحث.
- [ ] جميع الأجزاء الواجبة موجودة، ولا يوجد قسم مُختلَق لمجرد الحشو.
- [ ] الإهداء والآية والشكر والملخص فقط عند الطلب أو السياق المناسب.

## المحتوى والمصادر

- [ ] المقدمة تطرح المشكلة والأهداف، والمنهج مناسب لها.
- [ ] الأرقام والنتائج لها بيانات حقيقية أو مصدر واضح.
- [ ] الاستنتاجات تتبع التحليل، والتوصيات تتبع الاستنتاجات.
- [ ] لم تُختلق مراجع أو اقتباسات أو صفحات أو روابط.
- [ ] الالتزام بأسلوب التوثيق واكتمال الإحالات داخل المتن والقائمة.
- [ ] في التحرير: لا حذف لمضمون الطالب ولا اختصار دون تصريح.

## اللغة والتنسيق

- [ ] تدقيق إملائي ونحوي، توحيد المصطلحات، وربط الفقرات.
- [ ] Heading styles حقيقية وليست تنسيقات بصرية فقط.
- [ ] الخط والأحجام والتباعد والهوامش والمحاذاة حسب التكليف.
- [ ] الصفحة الأولى والصفحات التمهيدية وترقيم بداية المتن صحيح.
- [ ] الفهرس والتسميات والجداول والأشكال متسقة ومحدّثة.
- [ ] لا صفحات زائدة أو فراغات غير ضرورية.
- [ ] فحص ملفات DOCX وPDF بصرياً صفحة بصفحة بعد التصدير.

## التسليم

- [ ] اسم الملف واضح، والملف النهائي قابل للفتح.
- [ ] التنبيه لأي مصادر ناقصة أو بيانات تجريبية أو فهرس يحتاج تحديثاً.
- [ ] نسخة العمل الأصلية محفوظة عند وجود تحرير لملف مسبق.
